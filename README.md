# Интернет-магазин дизайнерских ламп «ОРБИТА»

## Название проекта

Интернет-магазин дизайнерских ламп «ОРБИТА»

## Разработка HTML и CSS

Проект представляет собой многостраничный интернет-магазин дизайнерских ламп и предметов интерьера, разработанный с использованием HTML, CSS и JavaScript.

---

## Тема контрольной работы

Тема: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы реализован многостраничный HTML/CSS-сайт интернет-магазина дизайнерских ламп «ОРБИТА».

Основной задачей проекта является создание современного адаптивного интерфейса интернет-магазина с несколькими страницами, каталогом товаров, карточками продукции, формой обратной связи и интерактивными элементами.

---

## Краткое описание проекта

«ОРБИТА» — интернет-магазин дизайнерских ламп и предметов декора для интерьера.

Сайт выполнен в минималистичном стиле с использованием светлой цветовой гаммы, крупных типографических элементов, фотографий интерьеров и скруглённых элементов интерфейса.

На сайте пользователь может:

- ознакомиться с ассортиментом дизайнерских ламп;
- посмотреть новые товары;
- перейти в каталог;
- использовать фильтры и сортировку товаров;
- открыть карточку товара в модальном окне;
- ознакомиться с описанием и стоимостью товара;
- перейти на страницу «О нас»;
- найти контактную информацию;
- заполнить форму обратной связи;
- просматривать сайт с различных устройств.

## Инструкция по просмотру проекта

Для просмотра проекта необходимо открыть файл `index.html` в браузере.

Для просмотра отдельных страниц используются файлы:

- `index.html` — главная страница;
- `about.html` — страница «О нас»;
- `catalog.html` — каталог товаров;
- `contacts.html` — страница контактов.

## Описание обязательных страниц

### Главная страница — `index.html`

На главной странице представлены логотип магазина «ОРБИТА», навигационное меню, основной баннер с описанием магазина и кнопкой перехода в каталог, а также блок с новыми товарами.

### Страница «О нас» — `about.html`

Страница содержит информацию о магазине, описание концепции, фотографии интерьеров и статистические показатели.

### Страница «Каталог» — `catalog.html`

На странице каталога представлены дизайнерские лампы в виде карточек товаров.

Реализованы категории, фильтры, сортировка и интерактивное открытие карточки товара в модальном окне.

### Страница «Контакты» — `contacts.html`

На странице размещена контактная информация магазина:

- телефон;
- электронная почта;
- адрес;
- график работы.

Также реализована форма обратной связи и изображение интерьера.

## Описание самостоятельных доработок

В ходе выполнения работы самостоятельно были реализованы:
